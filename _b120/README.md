# پروندهٔ ب۱۲۰ ـ بانک ملت

این پوشه گزارش فارسیِ پژوهش اسنادی دربارهٔ ارتباطات عمومی و روابط عمومی **بانک ملت** را نگه می‌دارد. هدف از فهرست اصلی با شناسهٔ `B-120` مشخص شده و با شرکت سرمایه‌گذاری ملت (`F-084`) و شرکت پرداخت «به‌پرداخت ملت» یکی نیست.

## محتویات

- `B120_REPORT_FINAL.md` — گزارش تحلیلی در ۱۲ حوزهٔ ممیزی؛ نسخهٔ فعلی توسعه‌یافته اما میانی است و ممیزی اسنادی شبکه‌های اجتماعی/پیام‌رسان‌ها را هم دارد.
- `B120_REPORT_FINAL.docx` — فایل Word با راست‌چین، جلد، فهرست و دفتر شواهد پیوست.
- `B120_EVIDENCE_LEDGER.md` — ۱۱۱ شناسهٔ کاری، با ثبت نوع منبع، محدودیت وارسی و هشدار خوشه‌بندی. شناسه‌ها یا URLها معادل منبع مستقل نیستند.
- `B120_SOURCE_AUDIT.md` — تعریف استقلال و ممیزی مقدماتیِ خوشه‌ها؛ گیت کامل استقلال همچنان باز است.
- `build.py` و `requirements.txt` — ساخت مجدد DOCX از گزارش و دفتر شواهد.
- `qa.py` — بررسی ساختاری ۱۲ حوزه، ارجاعات، تکرار خطی و DOCX؛ گیت‌های تکمیل باز را صریح اعلام می‌کند.
- `B120_HANDOFF.md` — وضعیت، شمار آخرین QA و کارهای باز.

## بازسازی Word و QA

از ریشهٔ مخزن، در صورت نبود محیط مجازی:

```bash
python3 -m venv .venv
.venv/bin/pip install -r _b120/requirements.txt
```

سپس ساخت و آزمون:

```bash
.venv/bin/python _b120/build.py
.venv/bin/python _b120/qa.py
```

وابستگی‌ها در `_b120/requirements.txt` ثبت شده‌اند. قلم B Nazanin در فایل تعبیه نشده و باید روی دستگاه مشاهده‌گر نصب باشد.

## وضعیت پذیرش

برش شواهد **۲۱ اکتبر ۲۰۲۶ UTC** است. آخرین شمار QA: **۳۳٬۴۴۴ واژهٔ کل متن گزارش** و **۳۱٬۰۳۶ واژهٔ تحلیلیِ نثری** (با حذف سطرهای عنوان/جدول)، ۱۲ حوزه و ۱۲۴ شناسهٔ کاری. ارجاع ناشناخته و خط تکراری دقیق صفر است. ۱۲۱ نشانی خام یکتا (۱۲۰ پس از نرمال‌سازی محدود)، اما اینها شمار منبع مستقل نیستند. گیت ۳۰٬۰۰۰ واژه بر اساس شمار نثری **PASS** است؛ گیت ۱۰۰ منبع مستقل همچنان `NOT_ASSESSED` است. اطلاعات پویا و پست‌های پس از تاریخ قطع از ممیزی شبکه‌های اجتماعی کنار گذاشته شده‌اند. این نسخه «کامل هم‌سطح `_f161/`» نیست و نباید چنین معرفی شود.
