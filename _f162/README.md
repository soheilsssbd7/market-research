# پروندهٔ پژوهشی بانک صادرات ایران (F–162)

بسته شامل گزارش تحلیلی فارسی با **ممیزی صریح همان ۱۲ حوزهٔ روابط عمومی F–161**، دفتر شواهد با منشأ/محدودیت و خوشه‌بندی بازنشرها، مولد DOCX و نسخهٔ Word است. هر حوزه حکم مقدماتی، سطح اطمینان و شکاف داده دارد؛ «دادهٔ ناکافی» معادل نمرهٔ منفی نیست. تاریخ قطع شواهد: **۲۱ اکتبر ۲۰۲۶ UTC**.

## فایل‌ها

- `F162_REPORT_FINAL.md` — متن اصلی گزارش.
- `F162_EVIDENCE_LEDGER.md` — دفتر ۲۶ ردیفی؛ ردیف‌ها منابع مستقل محسوب نمی‌شوند.
- `F162_REPORT_FINAL.docx` — گزارش قالب‌بندی‌شده با جلد، فهرست، سربرگ/پاصفحه، جدول‌ها، پیوندهای قابل‌کلیک و کارت‌های دفتر شواهد.
- `build.py` — ساخت مجدد DOCX از دو فایل Markdown.
- `F162_HANDOFF.md` — خلاصهٔ کنترل کیفیت و محدودیت‌های تحویل.

## ساخت مجدد

```bash
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python build.py
```

مولد از `python-docx` استفاده می‌کند و فونت **B Nazanin** را در سبک‌ها و runها درخواست می‌کند. فونت در خود فایل تعبیه نشده؛ برای وفاداری رندر باید روی دستگاه خواننده نصب باشد. اگر نصب نیست، Word فونت جایگزین انتخاب می‌کند و شکستگی صفحه/چیدمان ممکن است تغییر کند.

## دامنه و احتیاط

این پرونده پیمایش نمایندهٔ مشتریان، ممیزی فنی یا حسابرسی صورت‌های مالی نیست. چند خبر از یک بیانیه یا خبر اولیه بازنشر شده‌اند؛ دفتر خوشه‌ها را مشخص می‌کند و شمار ردیف‌ها را معادل استقلال نمی‌گیرد. نظرهای آنلاین و بازخوردهای مشتریان نمونهٔ خودانتخاب‌شده‌اند. گزارش اولیهٔ مرداد و تکذیب روابط‌عمومی بانک دو روایت متعارض‌اند و بدون دادهٔ دفتر کل/تعداد موارد نمی‌توان آن‌ها را قطعی آشتی داد.
