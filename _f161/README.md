# پروندهٔ F-161 — بانک پاسارگاد

این پوشه بستهٔ گزارش تحلیلی فارسی دربارهٔ شواهد عمومی ارتباطات و تجربهٔ مشتری بانک پاسارگاد را نگه می‌دارد.

## فایل‌ها

- `F161_REPORT_FINAL.docx` — گزارش Word با جلد، فهرست بخش‌ها، سرصفحه/پاصفحه، شمارهٔ صفحه، جدول‌های قالب‌بندی‌شده، پیوندهای قابل‌کلیک و پیوست دفتر شواهد.
- `F161_REPORT_FINAL.md` — متن منبع گزارش و معیارهای روش‌شناختی.
- `F161_EVIDENCE_LEDGER.md` — ۱۱۰ ردیف شواهد/سرنخ با منشأ و محدودیت استنباط.
- `build.py` و `requirements.txt` — ساخت مجدد DOCX از Markdown و ledger.
- `F161_HANDOFF.md` — وضعیت، QA، محدودیت‌ها و ادامهٔ کار.

## ساخت DOCX

از ریشهٔ مخزن اجرا کنید:

```bash
python3 -m venv .venv
.venv/bin/pip install -r _f161/requirements.txt
.venv/bin/python _f161/build.py
```

قلم در سبک‌ها و متن فایل Word روی **B Nazanin** تنظیم شده است. فایل قلم در این بسته تعبیه نشده؛ برای نمایش دقیق، B Nazanin باید روی دستگاه بازکننده نصب باشد. پس از بازسازی، `.venv/` را به مخزن اضافه نکنید.

## وضعیت اعتبارسنجی

- تاریخ قطع شواهد: ۲۱ اکتبر ۲۰۲۶ UTC.
- معیار بدنه: ۳۲٬۱۸۰ قطعهٔ فاصله‌محور و ۳۱٬۸۱۴ قطعهٔ دارای نویسهٔ فارسی (پس از حذف URL و شناسه‌های ارجاع)، از خلاصهٔ اجرایی تا پیش از منابع؛ جلد، فهرست و پیوست خارج از معیارند.
- ledger دارای ۱۱۰ ردیف خام است؛ شمار خوشه‌های مستقلِ واجدشرط هنوز تعیین نشده و معیار ۱۰۰ منبع مستقل **احراز نشده** است. شمار خام را نباید معادل شمار منابع مستقل گرفت.
- DOCX شامل ۹۹۶ پاراگراف و ۶ جدول است؛ پیوست منبع‌ها را به کارت‌های قابل‌خواندن تبدیل می‌کند.
